# Traffic Sign Detection with YOLO

## 🚦 Overview
This project detects traffic signs in real-time using YOLOv8 and computer vision.

## ✨ Features
- Real-time webcam detection
- ROI zooming for better accuracy
- Writes predicted class to output file

## 🧠 Requirements
- Python 3.10+
- ultralytics
- opencv-python

## 🔧 Installation
git clone https://github.com/tanerbayramm/Traffic_Sign_Recognation
cd traffic-sign-detection
pip install -r requirements.txt

## ▶ Run
python src/model.py
